T-Money Icon System

20 duotone icons on a 24×24 grid, plus logo, launcher icons and design tokens. Click any icon to copy its snippet.

Icon library

Eight core finance icons from the branding sheet, plus twelve interface icons in the same style.

Sizes

Vector at every size. 16–20 px for inline text, 24 px for nav and lists, 32–48 px for feature tiles.

Tones

Every icon reads four CSS variables, so a class is enough to retint it — no second file.

Type

Montserrat Bold — headings, balances, numbers

Open Sans Regular — body copy, labels and long-form guidance. Use tabular figures (font-feature-settings:'tnum') for any column of currency.

How to use

Web — sprite (recommended)

<link rel="stylesheet" href="tokens/tm-tokens.css">
<link rel="stylesheet" href="tokens/tm-icons.css">

<!-- paste sprite/tm-icons-sprite.svg once, right after <body> -->

<svg class="tm-icon"><use href="#tm-accounts"/></svg>

Web — single file

<img src="svg/tm-accounts.svg" width="24" height="24" alt="">

<!-- or as a CSS mask, tinted by color -->
.icon-accounts{
  -webkit-mask:url(svg/tm-accounts.svg) center/contain no-repeat;
          mask:url(svg/tm-accounts.svg) center/contain no-repeat;
  background:currentColor;
}

React Native / Expo

import { SvgXml } from 'react-native-svg';
import xml from './svg/tm-accounts.svg';

<SvgXml xml={xml} width={24} height={24} />
